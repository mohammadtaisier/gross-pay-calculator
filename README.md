# Gross Pay Calculator by Python

# Project Overview (About)
This is my first programming project in Python. The program calculates the employee's gross pay based on user inputs, taking into account regular and overtime hours, and includes a mechanism to protect the program from crashing when invalid data is entered.

 Program Features (Features)
1. **Reading Inputs:** Prompts the user to enter the number of working hours, pay rate, and overtime hours.
2. **Error Handling:** Uses `try / except` to ensure the user enters valid numbers and prevents the program from crashing.
3. **Dynamic Wage Calculation:** Automatically calculates regular pay and overtime premium pay using conditions (`if / else`).

# Language Used
- Python 3
